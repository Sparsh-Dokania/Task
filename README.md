# ✨ Overview

This project started as an interview assignment:

> Recreate a floating legal-tech hero section using Next.js.

Instead of building a static copy, the goal evolved into creating:

- an accurate production-quality recreation  
- a scalable component architecture  
- a motion-enhanced creative version  
- a polished legal-tech UI system  

The project now contains:

- ⚖️ **Reference Mode** → pixel-accurate recreation  
- 🚀 **Creative Mode** → enhanced premium interpretation  

---

# 🎯 Core Features

## ⚖️ Reference Mode
A faithful recreation of the provided assignment design:

- floating legal workflow cards  
- responsive split layout  
- soft blurred background elements  
- accurate typography hierarchy  
- production-grade responsiveness  

---

## 🚀 Creative Mode
An elevated motion-first version featuring:

- advanced GSAP interactions  
- layered floating depth  
- enhanced legal-tech visual system  
- cinematic transitions  
- premium motion polish
